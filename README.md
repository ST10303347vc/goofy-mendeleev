# Goofy Mendeleev App

A comprehensive fitness, habit, and task tracker with gamification elements.

## Features
* Daily workout protocols
* Habit tracking with streaks
* Task management with subtasks
* Water logging
* Gamification system with points and shopping items

## Requirements
* Python 3
* Flask
* SQLite

## Installation
1. Clone the repository.
2. Execute `bash run.sh` in the terminal to set up the virtual environment, install dependencies, and start the application.
3. Open your browser and navigate to http://localhost:8000

## Structure
* `backend/` : Contains the Flask server and SQLite database setup.
* `frontend/` : Contains the HTML, CSS, and JS files for the user interface.
* `run.sh` : Script to launch the application.
* `add_workouts.py` : Script to add custom workouts to the database.
